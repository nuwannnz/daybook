# CaptureBar

The one input that saves any task or thought in two seconds, at the top of Today and behind ⌘K.

- Enter saves and keeps focus for the next item; the field never asks where something goes.
- `#tag` files the item under a project; untagged items land in Inbox. Show parsed tags as chips before saving.
- The only element on a desktop view besides auth cards that uses `shadow-card`.
- The Add button is the view's primary action; the `Enter` kbd hint sits beside it.
