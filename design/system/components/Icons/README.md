# Icons

Daybook's line icons: inline SVG on a 24-unit grid, `stroke="currentColor"`, round caps and joins, no fills.

- Stroke 1.75 in navigation, 2 in buttons; render at 16, 18 or 22px.
- Copy the SVG markup from this card; icons take their colour from the surrounding text.
- Decorative icons get `aria-hidden="true"`; an icon-only button carries `aria-label`.
- No emoji and no filled icon styles.
