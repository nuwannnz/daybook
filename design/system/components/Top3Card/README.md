# Top3Card

One of the day's three focus tasks: numbered, coloured by project, with a checkbox at the end.

- At most three per day. Pinning a fourth asks which one to swap out.
- The number badge takes the project's tone; the chip repeats the project name for people who can't tell the colours apart.
- 60px minimum height and `task` type (15/22 medium): bigger than ordinary task rows on purpose.
