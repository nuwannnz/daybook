# Roadmap

Derived from the release plan in the [PRD](../product/PRD.md#release-plan). Dates are not set; each gate is a go / no-go review.

| Phase | Scope | Gate to exit |
| --- | --- | --- |
| MVP (private beta) | All P0: capture and tags, Today, carry-over, week board, projects, notes editor, offline and sync, responsive web | Sync loses no data; testers use it daily |
| v1 (public launch) | All P1: schedule and calendar, natural-language dates, weekly review, pinned decisions, note links, shortcuts, dark mode, desktop PWA | AA audit clean; retention on target |
| v1.1 | iOS and Android apps, native capture, to-do app imports, AI agents | Mobile matches web for capture and Today |
| Later | P2 backlog | — |
